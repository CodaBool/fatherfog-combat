# Fatherfog Combat
> this is written for the Mothership Foundry system. It hardcodes values for getting HP from that system

- Implements Fatherfog combat rules in Foundry. Players can skip or delare their action. Turns are under a timer.

## What is Fatherfog Combat?

> rounds simulate 10 seconds

1. the GM lays out what will happen if no one acts. For example player 1 will be attacked by the enemy
2. By random order, each player declares their action within the timer. Or skips to be come back to later
3. Once everyone has declared their actions the GM gives rolls to everyone if applicable. 

> IMPORTANT: Enemies are not given an initiative order instead their effect is determined on the targeted player's turn.
